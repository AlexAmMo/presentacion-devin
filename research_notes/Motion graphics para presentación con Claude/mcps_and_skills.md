# MCP servers, Agent Skills, Claude Code plugins and connectors for motion graphics / animated HTML presentations with Claude (state as of 14 Oct 2026)

Method note: GitHub star counts, last-push dates and archived flags were pulled live from the GitHub API on 2026-10-14 (cited as the repo URL). npm download counts are from the npm downloads API, period 2026-09-13 to 2026-10-12 (cited as `api.npmjs.org`). Install counts are from the public pages at claude.com/plugins and skills.sh, fetched 2026-10-14. "Relevance" ratings, for building an animated HTML presentation, are my own inferences and are labeled as such.

## Q0. Catalog: which tools exist, who maintains them, what they do, how to install them, what they cost, and how mature they are

### Takeaway
The stack that matters most for an animated **HTML** presentation is small. It has three parts: (1) official animation-library skills (GSAP, Motion, Anthropic's `frontend-design`); (2) HTML-native video and motion frameworks with agent skills (HeyGen **HyperFrames**, **Remotion**); (3) browser-QA MCPs that let Claude see what it built (**Playwright MCP**, **Chrome DevTools MCP**, **Claude in Chrome**), plus **Context7** for library docs. Almost every design-tool and creative-app MCP (Figma, Canva, LottieFiles, Rive, Webflow, Blender, Adobe and others) is free to connect. They are gated by the paid plan or seat of the underlying tool.

### Cited Findings

#### A. Code-based motion engines and their official agent skills (core for HTML animation)

**A1. Remotion Agent Skills (`remotion-dev/skills`): OFFICIAL (Remotion)**
- What: a set of skills that "define best practices for working in Remotion projects," maintained by Remotion and built on the Agent Skills standard. Skills: `/remotion-best-practices`, `/remotion-create`, `/remotion-markup` (animation, layout, typography, timing), `/remotion-studio`, `/remotion-render` (renders a video **or still**), `/remotion-maps`, `/remotion-captions`, `/remotion-saas`, `/remotion-interactivity`, `/remotion-docs` (searches the docs and fetches pages as Markdown), `/remotion-upgrade`, `/remotion-multimedia` — [Remotion docs: Agent Skills](https://www.remotion.dev/docs/ai/skills); the folder list is confirmed in [GitHub remotion-dev/skills](https://github.com/remotion-dev/skills)
- Install: `npx skills add remotion-dev/skills`, or add the skills during `bun create video`. The page names Claude Code, Codex, Kimi Code and Cursor as supported agents — [Remotion docs](https://www.remotion.dev/docs/ai/skills). The CLI alternatives are `npx remotion skills add` and `npx remotion skills update`. Skills install to `.agents/skills`, and `.claude/skills` is symlinked to it — [Remotion CLI docs](https://www.remotion.dev/docs/cli/skills)
- Official Claude Code plugin: `claude plugin marketplace add remotion-dev/claude-code-plugin`, then `claude plugin install remotion@remotion`. The main command is `/remotion:remotion-create <prompt>`. In the Desktop app, use Code → Customize → Plugins → Discover → "remotion" — [Remotion docs: Claude Code plugin](https://remotion.dev/docs/ai/claude-code-plugin). The plugin repo has 48★ and was created 2026-07-16 — [GitHub remotion-dev/claude-code-plugin](https://github.com/remotion-dev/claude-code-plugin)
- Not in Anthropic's official plugin marketplace. Remotion does not appear in `anthropics/claude-plugins-official` marketplace.json (315 plugins checked) — [GitHub anthropics/claude-plugins-official](https://github.com/anthropics/claude-plugins-official). A third-party repackaging, `pasie15/remotion-skills-marketplace`, has 0★ — [GitHub](https://github.com/pasie15/remotion-skills-marketplace)
- Maturity: the skills repo has 5,129★, was created 2026-01-19 and was last pushed 2026-10-12 — [GitHub remotion-dev/skills](https://github.com/remotion-dev/skills). The main `remotion` repo has 64,005★ — [GitHub remotion-dev/remotion](https://github.com/remotion-dev/remotion). The `remotion` npm package had 8,406,351 downloads in the last month, all uses included — [npm API](https://api.npmjs.org/downloads/point/last-month/remotion). `remotion-best-practices` has 615.1K installs (rank 66) on skills.sh — [skills.sh](https://skills.sh/)
- Price: the skills are free. Remotion itself is **free for individuals and companies of up to 3 people**. Above that: "Remotion for Creators" costs $25/seat/month; "Remotion for Automators" costs $0.01/render with a $100/month minimum; Enterprise starts at $500/month — [Remotion pricing](https://www.remotion.dev/docs/license/pricing)
- Relevance (inference): **medium.** Remotion renders MP4s or stills from React. It fits best if the presentation needs exported video segments, less well for a live HTML deck.

**A2. Remotion Documentation MCP (`@remotion/mcp`): OFFICIAL, docs only**
- Indexes the Remotion docs into a vector database using CrawlChat technology. It is a documentation helper, not a renderer. Setup runs `npx @remotion/mcp@latest` under the server name "remotion-documentation". It is "open without authentication" for now, but Remotion warns it "might restrict the usage" if costs grow — [Remotion docs: MCP](https://remotion.dev/docs/ai/mcp)
- Price: free (for now).
- Community MCPs that actually render exist, such as "remotion-mcp" (render MP4, stills, GIF) and the "Remotion MCP App" with an inline Player widget. They are small and unofficial — [mcp.so remotion-mcp](https://mcp.so/server/remotion-mcp/Vidhanvyrs); [Glama Remotion MCP App](https://glama.ai/mcp/servers/smarot6/remotion-mcp-app)

**A3. HyperFrames by HeyGen (`heygen-com/hyperframes`): OFFICIAL (HeyGen), open source**
- What: "Write HTML. Render video. Built for agents." A composition is an HTML file with data attributes for timing and tracks. The renderer seeks each frame in headless Chrome and encodes with FFmpeg, so output is deterministic. Compositions preview directly in a browser with no build step. Supported adapters: **GSAP, Lottie, Three.js, Anime.js, CSS animations, WAAPI, TypeGPU** — [GitHub heygen-com/hyperframes](https://github.com/heygen-com/hyperframes)
- Skills folder includes `hyperframes`, `hyperframes-animation`, `hyperframes-keyframes`, `hyperframes-creative`, `motion-graphics`, **`slideshow`**, `figma`, `remotion-to-hyperframes`, `product-launch-video`, `pr-to-video`, `music-to-video`, `embedded-captions` and others — [GitHub hyperframes/skills](https://github.com/heygen-com/hyperframes/tree/main/skills)
- Install: Claude Code plugin `claude plugin marketplace add heygen-com/hyperframes`, then `claude plugin install hyperframes@hyperframes`. Alternatively `npx skills add heygen-com/hyperframes`, or the local CLI `npx hyperframes init my-video`. Requires Node 22+ and FFmpeg — [GitHub](https://github.com/heygen-com/hyperframes). It is also listed in Anthropic's official marketplace as plugin "hyperframes" (category: design) — [anthropics/claude-plugins-official](https://github.com/anthropics/claude-plugins-official)
- Hosted connector: "HyperFrames by HeyGen," described as "Build animated slides and motion graphics with HTML." It is in the Claude connectors directory (added June 2026), exposes the tools `compose` and `render_video`, uses the URL `https://mcp.heygen.com/mcp/hyperframes`, and requires sign-in — [claude.com/connectors/hyperframes](https://claude.com/connectors/hyperframes). The hosted connector is in **beta**, requires a HeyGen account (OAuth) and renders on HeyGen infrastructure. The docs give no price and say "credits and plan requirements can change" — [HyperFrames MCP guide](https://hyperframes.heygen.com/guides/mcp)
- Price: open source under Apache-2.0 with "no per-render fees or commercial-use thresholds" for local rendering — [GitHub](https://github.com/heygen-com/hyperframes). Pricing for hosted cloud rendering is not published (see Gaps).
- Maturity: 63,203★, created 2026-03-10, pushed 2026-10-14 — [GitHub](https://github.com/heygen-com/hyperframes). The `hyperframes` npm package had 2,652,201 downloads in the last month — [npm API](https://api.npmjs.org/downloads/point/last-month/hyperframes). skills.sh installs: `hyperframes-cli` 1.0M (rank 7), `hyperframes` 961.9K (rank 11), `hyperframes-animation` 853.1K, `motion-graphics` 446.1K, `remotion-to-hyperframes` 448.3K — [skills.sh](https://skills.sh/). On claude.com/plugins the plugin shows only 2,119 installs — [claude.com/plugins/hyperframes](https://claude.com/plugins/hyperframes). Launched 17 Apr 2026; HeyGen says its own launch video was made in Claude Code with HyperFrames — [Noqta](https://www.noqta.tn/en/blog/heygen-hyperframes-html-to-mp4-ai-agent-video-2026). HeyGen also shipped it as a Codex plugin and as a **skill for Claude Design** (secondary source) — [Creators Toolbox](https://creatorstoolbox.beehiiv.com/p/heygen-brings-hyperframes-to-claude-and-codex)
- Related community kit: `nateherkai/hyperframes-student-kit`, 1,409★, "14 skills" for editing reels and Shorts with Claude Code — [GitHub](https://github.com/nateherkai/hyperframes-student-kit)
- Relevance (inference): **very high.** It is HTML/GSAP-native, previews in a browser, has a `slideshow` skill, and the same source can be exported to MP4.

**A4. GSAP official skills (`greensock/gsap-skills`): OFFICIAL (GreenSock, owned by Webflow)**
- Skills: `gsap-core`, `gsap-timeline`, `gsap-scrolltrigger`, `gsap-plugins` (Flip, SplitText, ScrollSmoother, Draggable and others), `gsap-utils`, `gsap-react`, `gsap-performance`, `gsap-frameworks` — [GitHub greensock/gsap-skills](https://github.com/greensock/gsap-skills)
- Install: `npx skills add https://github.com/greensock/gsap-skills`. In Claude Code: `/plugin marketplace add greensock/gsap-skills`. Cursor uses a remote rule; manual copy into `~/.claude/skills/` also works. The repo is MIT-licensed — [GitHub](https://github.com/greensock/gsap-skills)
- Price: the README states "GSAP is 100% free — including every plugin." Former Club plugins such as SplitText and MorphSVG became free for commercial use after the Webflow acquisition — [GitHub](https://github.com/greensock/gsap-skills)
- Maturity: 16,356★, created 2026-03-04, last pushed 2026-07-29 — [GitHub](https://github.com/greensock/gsap-skills). The `gsap` npm package had 24,418,062 downloads in the last month — [npm API](https://api.npmjs.org/downloads/point/last-month/gsap). Many copies of these skills circulate on marketplaces, for example `nexu-io/open-design/gsap-core` — [claudemarketplaces.com](https://claudemarketplaces.com/skills/nexu-io/open-design/gsap-core)
- Not in Anthropic's official marketplace (not found in marketplace.json) — [anthropics/claude-plugins-official](https://github.com/anthropics/claude-plugins-official)
- Relevance (inference): **very high.** Timelines, ScrollTrigger and SplitText are the standard toolkit for animated web slides.

**A5. Motion AI Kit (motion.dev): OFFICIAL (Motion, formerly Framer Motion)**
- What: an MCP server plus skill. It provides current Motion docs, saved transitions and the source of 490+ premium examples; **MotionScore for Agents**, which audits code, can profile a running local site and grades animations by render cost; CSS spring generation as `linear()` easings via the `/motion` skill; and a visual transition editor inside the chat or IDE — [Motion AI Kit](https://motion.dev/docs/ai-kit). Install guide: motion.dev/docs/ai-kit-install — [Motion AI Kit](https://motion.dev/docs/ai-kit)
- Price: **free** tier covers best practices and docs search, with no account needed. **Motion+** unlocks spring generation, MotionScore, the transition editor and premium source — [Motion AI Kit](https://motion.dev/docs/ai-kit). Motion+ Solo costs **$399 one-time** (lifetime updates), a price taken from the page's structured data. Team is billed annually per seat; that price is not shown — [motion.dev/plus](https://motion.dev/plus). The changelog says unauthenticated users get the docs and CSS generation tools — [Motion changelog](https://motion.dev/changelog?type=major)
- Maturity: the `motion` library has 34,089★ — [GitHub motiondivision/motion](https://github.com/motiondivision/motion) — and 104,728,505 npm downloads in the last month — [npm API](https://api.npmjs.org/downloads/point/last-month/motion)
- Community alternative: `Abhishekrajpurohit/motion-dev-mcp`, an offline docs database with about 15★ (small) — [GitHub](https://github.com/Abhishekrajpurohit/motion-dev-mcp); [Glama](https://glama.ai/mcp/servers/pz8nupxaql)
- Relevance (inference): **high** if the deck is built in React or vanilla JS with Motion.

### Inferences
- For an **animated HTML presentation**, my recommended core set is: `frontend-design` (art direction) + **GSAP skills** (or the Motion AI Kit if building in React) + optionally **HyperFrames** (HTML-native, has a `slideshow` skill, exports MP4 from the same source) + **Playwright MCP or Chrome DevTools MCP** (screenshots, screencast/video, performance traces) + **Context7**. Everything in this core set is free apart from optional Motion+ or Context7 Pro.
- Remotion is the incumbent for "Claude makes a video," but it is React-to-MP4. HyperFrames targets the same use case with plain HTML and GSAP, and ships a `remotion-to-hyperframes` migration skill. That positioning suggests HeyGen is competing directly for Remotion's agent users.
- Design-tool MCPs (Figma, Canva, Penpot, Webflow, Framer) mainly move static layout and tokens into code. None of them authors web animation timelines. Lottie Creator and Rive are the exceptions: they author animation assets that can be embedded in HTML.
- Pro-app MCPs (After Effects, Premiere, Cinema 4D, Resolve) are community projects for paid desktop apps. They are useful for video pipelines but tangential to an HTML deck. Blender software is free, so its official connector carries no software cost; this rests on general knowledge, since no fetched source states it.

## Q2. Exact pricing and free status: is the MCP free while the underlying service is paid?

### Takeaway
Almost all connectors and skills are **free to install**. Cost comes from (a) the underlying tool's seat or plan (Figma Dev/Full seat, Canva/Claude paid plans, Adobe, After Effects, Resolve Studio), (b) usage credits (fal, Runway, Higgsfield, ElevenLabs, Replicate), or (c) optional premium tiers (Motion+ $399 one-time; Context7 Pro $10/seat/month; Remotion company license if the organization has more than 3 people). The core HTML-animation stack (GSAP, frontend-design, HyperFrames local, Playwright/DevTools MCP) costs $0.

### Inferences
