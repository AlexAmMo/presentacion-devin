Crema, navy y rojo

La dirección C con una paleta centrada en los colores más representativos de Openbank: Prussian blue, Pickled bluewood y el rojo de la marca. Todas las variables están en design-system.css, y esta página solo usa esas variables. Haz clic en cualquier lámina para verla grande; con ← → pasas de una a otra y con F la ves a pantalla completa.

01

Color

Cinco colores de marca hacen todo el trabajo: navy para el contenido y rojo para el foco. Las cremas son el suelo de la dirección C y el blanco separa las superficies. Los tres rojos son el mismo rojo según el fondo, así que cuentan como un único acento.

Neutros de apoyo

Semántica: todo sale de navy; cambia el relleno, no el tono

Tokens de entrada

Relleno sólido Prussian, texto blanco. --color-entrada

Arregla·la
Tokens de salida

Hueca: blanco con contorno navy de 3 px. --color-salida --color-salida-borde

Cambio
Tokens de razonamiento

Rayado navy al 40 %. --patron-razonamiento

Reviso
Caché acertada

Corchete continuo Bluewood + ✓. --color-cache-acierto

Caché fallida

Corchete discontinuo Bluewood + ✕. --color-cache-fallo

Coste

Píldora navy con monedas y cifra en mono. --color-coste

● 0,050 u.

Por qué no hay más tonos: la paleta se ciñe a la marca y los conceptos se distinguen por la luminosidad (oscuro, medio, hueco) y por la forma (sólido, rayado, contorno, continuo o discontinuo). Así siguen legibles con el proyector lavado y para personas con daltonismo. El precio: acierto y fallo de caché no tienen color propio. Se separan por el trazo y el icono.

Espaciado, radios, trazos y elevación

Base de 8 px. Formas redondeadas, como en la dirección C, y contornos navy de 3 px que separan las superficies, porque el proyector iguala las cremas. Hay una única elevación, plana, porque las sombras difusas desaparecen al proyectar.

Espaciado

Zona segura de escena: --margen-x 120 px · --margen-y 96 px.

Radios

--radio-m 24
--radio-l 48
--radio-pildora

12: capas, código y documentos · 24: tarjetas (agente, skill) · 48: islas y recipiente · píldora: fichas, etiquetas y contadores.

Trazos (compatibles con Lucide, 2 px sobre 24)
--trazo-fino 2 separadores, escalas

Iconos a 24 / 36 / 48 px con stroke-width 2: a 36 px el trazo real es 3 px, igual que el contorno.

06

Reglas

  • Un solo acento por pantalla. El rojo marca lo que hay que mirar ahora: la zona actual, el nivel de llenado o la cifra protagonista. Nunca hay dos elementos rojos a la vez.
  • El rojo según el fondo: #DF0049 sobre claro, #FF0049 sobre navy y #E9004C solo dentro del logo, que nunca se recolorea.
  • Toda superficie lleva contorno navy de 3 px. El proyector iguala crema y blanco; el tono por sí solo no separa nada.
  • Nada por debajo de 24 px a 1920×1080. Contraste de texto ≥ 4,5:1, y ≥ 3:1 solo desde 24 px en adelante.
  • Sin decoración: nada de partículas, brillos, destellos, degradados, sombras difusas ni giros 3D decorativos.
  • Cada concepto, un único dibujo (ver vocabulario). Un token es siempre una píldora en DM Mono y la caché, siempre un corchete.
  • Las cifras de ejemplo son ficticias y se marcan así en la propia escena, con la etiqueta «Cifras ficticias» visible.
  • Iconos Lucide a 36 px con stroke-width 2 (trazo real de 3 px, igual que el contorno). A 24 px solo dentro de etiquetas.
  • La cámara nunca se mueve mientras algo se anima dentro de la zona. Primero llega la cámara, luego --pausa-tras-camara y después la zona.

08

Uso en código

Importa design-system.css una vez. En GSAP, las curvas y duraciones se leen de las variables, así un cambio aquí se propaga a toda la presentación.

// Leer variables del sistema desde GSAP
const raiz = getComputedStyle(document.documentElement);
const v = (n) => raiz.getPropertyValue(n).trim();   // 'power3.out'
const s = (n) => parseFloat(v(n));                   // '0.5s' → 0.5

gsap.from('.ficha', {
  y: 24, autoAlpha: 0,
  duration: s('--dur-entrada'),
  ease: v('--ease-aparicion'),
  stagger: s('--escalonado-tokens'),
});

// Cámara: llega, espera y después anima la zona
gsap.timeline()
  .to(mundo, { x, y, scale, duration: s('--dur-camara'), ease: v('--ease-camara') })
  .add(animarZona, `+=${s('--pausa-tras-camara')}`);

Ficheros: design/design-system.css (variables), design/assets/logos/ (logos oficiales), design/ronda-1-direcciones.html (las tres direcciones de partida).
